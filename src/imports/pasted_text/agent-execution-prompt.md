# 11. SECTION — WHAT AGENTSENTRY IS

Headline:

> **AN EXECUTION CONTROL PLANE FOR AI AGENTS**

Create six/seven architectural capability cards:

### Agent Identity

Know which autonomous actor is requesting execution.

### Tool Registry

Control which tools and immutable tool versions an agent can invoke.

### Deterministic Policy

Evaluate execution against explicit business and security rules.

### Human Approval

Require approval for transactions that cross defined thresholds or risk boundaries.

### Runtime Protection

Control rate limits, suspension, revocation, freshness and execution safety.

### Execution Ledger

Create evidence of what the agent attempted, what policy decided, what approval occurred and what actually executed.

### Tenant Isolation

Keep execution context and policy boundaries isolated across customers and environments.
